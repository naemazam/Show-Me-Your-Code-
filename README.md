# 📌 Show Me Your Code!!


**Show Me Your Code!!** is a monthly developer event where developers can submit their projects such as:

- 🌐 **Web Applications**
- 📱 **Mobile Applications**
- 🤖 **AI Tools**
- ⚙️ **Automation Tools**
- 💻 **Open Source Projects**
- 🔐 **Cybersecurity Projects**

## 📤 How To Submit Your Project
Submit your project through the form below:
